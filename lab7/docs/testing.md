# Результаты тестирования API

| № | Запрос | Ожидаемый код | Получен код | Комментарий |
|---|--------|---------------|-------------|-------------|
| 1 | GET /api/bookings | 200 | 200 | Список из 7 записей |
| 2 | GET /api/bookings/1 | 200 | 200 | Запись найдена |
| 3 | GET /api/bookings/999 | 404 | 404 | Ошибка "не найдено" |
| 4 | POST /api/bookings (валидный) | 201 | 201 | Запись создана (Тур в Сочи) |
| 5 | POST /api/bookings (короткое имя) | 422 | 422 | Ошибка валидации (название < 3 символов) |
| 6 | DELETE /api/bookings/8 | 204 | 204 | Запись удалена |
| 7 | GET /api/tours | 200 | 200 | Список туров |
| 8 | DELETE /api/tours/1 (связан с бронями) | 409 | 409 | Конфликт (нельзя удалить тур) |
| 9 | GET /api/clients | 200 | 200 | Список клиентов |
